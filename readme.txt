Thème WordPress sur mesure pour Rumhora — ACF, GSAP, Sass et Barba.js.

== Description ==

Thème sur mesure, non destiné à être utilisé comme thème parent. ACF Pro pour
les contenus, GSAP (ScrollTrigger, SplitText) pour les animations, Barba.js
pour les transitions de page, Lenis pour le smooth scroll, Swiper pour les
sliders. Les styles sont écrits en Sass avec Tailwind en couche d'utilitaires.

Voir README.md pour l'installation et la chaîne de build, et CLAUDE.md pour
les conventions d'architecture.

== Installation ==

1. Déposer le dossier du thème dans wp-content/themes/.
2. Lancer `npm install && npm run build` dans le dossier du thème.
3. Activer le thème depuis Apparence > Thèmes.
4. Installer ACF Pro (obligatoire pour les contenus éditables).
